# AI Content & Workflow Automation Prompts

A collection of structured prompts and templates for automating creative production, scriptwriting, and visual generation workflows.

## 1. Short-Form Video Hook Generator
**Role:** Expert social media strategist.
**Task:** Generate 5 high-retention opening hooks (under 3 seconds) for a vertical 9:16 video. Focus on curiosity gaps, direct problem-solving, and clear visual cues.

## 2. Motion Graphics Scene Breakdown
**Role:** Creative director and motion designer.
**Task:** Break down a 30-second script into sequential visual scenes. For each scene, specify:
- On-screen typography layout
- Camera movement / transition style
- Color palette and visual focus
